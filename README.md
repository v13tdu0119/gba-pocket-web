# GBA Pocket Web

Web app to play **your own** Game Boy Advance dumps in the browser. ROMs stay on the device that opens them — they are not bundled or uploaded.

**Live:** https://v13tdu0119.github.io/gba-pocket-web/

## Run locally

```bash
npm install
npm run dev
```

Put `.gba` or `.zip` files in `src/downloaded_roms`, or use **Mở ROM** on the stage. `npm run dev` rebuilds the catalog from that folder.

This repo does not include Nintendo BIOS, commercial ROMs, or a dump inventory. Use files you are allowed to have.
